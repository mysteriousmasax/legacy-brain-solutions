# Stitch Reference Archive

This folder contains source material retained from Stitch and other design exploration. It is not part of the Vite application runtime.

- `screens/`: exported page and responsive screen references.
- `generated-assets/`: generated logos, images, and prototype assets.
- `fallbacks/`: unreferenced browser fallback experiments.
- `research/`: extracted text and working notes.

The website itself remains in the workspace root, with React code in `src/`, API code in `server/`, and database files in `prisma/`.
